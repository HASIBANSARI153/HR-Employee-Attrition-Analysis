HR Employee Attrition Analysis

1. Project Overview
This project focuses on analyzing employee attrition to understand why employees leave an organization and identify factors that may influence employee turnover.

The analysis uses SQL, Python, Pandas, and Power BI to clean, analyze, and visualize HR employee data.

2. Project Objectives
- Analyze employee attrition rates.
- Understand department-wise employee turnover.
- Identify job roles with higher attrition.
- Analyze the impact of overtime on employee attrition.
- Study attrition by age group, gender, and marital status.
- Create an interactive HR analytics dashboard.

3. Tools & Technologies
- Microsoft Excel:- Dataset inspection and basic data handling.
- MySQL:- Data querying and analysis.
- Python:- Data cleaning and analysis.
- Pandas & NumPy:- Data manipulation.
- Matplotlib & Seaborn:- Data visualization.
- Power BI:- Interactive dashboard development.

4. Dataset Information
- Dataset: HR Employee Attrition Dataset
- Total Records: 1,470 (expected full dataset)
- Data Type: Employee and HR information
- Important Columns:
  - EmployeeNumber
  - Age
  - Gender
  - Department
  - JobRole
  - MonthlyIncome
  - OverTime
  - Attrition
  - JobSatisfaction
  - YearsAtCompany

5. Project Workflow

Phase 1: SQL Analysis
- Imported the HR dataset into MySQL.
- Performed employee counts and attrition analysis.
- Analyzed department-wise and job-role-wise attrition.
- Used SQL aggregate functions and GROUP BY.

Phase 2: Python Analysis
- Loaded the dataset using Pandas.
- Checked missing values and duplicate records.
- Cleaned unnecessary columns.
- Created Age Groups and Experience Groups.
- Performed exploratory data analysis.
- Created charts using Matplotlib and Seaborn.

Phase 3: Power BI Dashboard
- Created KPI cards.
- Visualized employee attrition.
- Analyzed attrition by department and job role.
- Created charts for overtime, age group, and job satisfaction.
- Added interactive slicers.

6. Key KPIs
- Total Employees
- Employees Left
- Employees Stayed
- Attrition Rate
- Average Age
- Average Monthly Income

7. Expected Project Outcomes
- Better understanding of employee attrition.
- Identification of departments and job roles with higher employee turnover.
- Understanding the relationship between overtime and attrition.
- Data-driven insights to support HR decision-making.
